The lab stub: a small Python program (lazydocker-lab/docker-stub.py) that
answers the Docker Engine API on loopback with invented fixture data.
Nothing in it can create, start or stop anything.

$ python3 docker-stub.py 18086
docker stub listening on 127.0.0.1:18086

$ curl -s -D- http://127.0.0.1:18086/_ping
HTTP/1.1 200 OK
Server: BaseHTTP/0.6 Python/3.12.3
Date: Tue, 03 Nov 2026 02:23:39 GMT
Content-Type: text/plain
Content-Length: 2
Api-Version: 1.47
Docker-Experimental: false
Ostype: linux

OK
